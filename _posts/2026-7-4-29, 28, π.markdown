嘿，你，还有你，29岁生日快乐，28周生日快乐！

有一天在看着3Blue1Brown的一个视频，我感叹了一下π是这样神奇的一个数字，然后你说那要不我们的儿子就叫派派吧，一听到这个名字，就马上爱上。

一个无限不循环小数，一个自然界天然存在的常量，一个藏在圆形和球体里的数。它有时候会很神奇地出现在你不会预料到的地方。一堆分数相加怎么会和它有关系？自然界最常见的分布也有它事？连揭示宇宙底层奥秘的不确定性原理里也有它身影？

就这样将宇宙的祝福赠给我们的小宝吧，还有，以后多了一个借口去吃各种各样的派。

不知道为什么，想到了去年四月你走在小区林荫小道上伤心哭泣的样子，傍晚温柔的阳光，时有时无徐徐的微风，微微招手微笑的树叶和斑驳的影子，还有沉默不语的我们俩。想起来那光景会觉得很安静，安静且悲伤。如此美好的世界一隅里，你的内心却空荡荡的，泪眼朦胧。我是这样的后知后觉，直到现在才开始仔细去感悟，去体验你当时的悲伤，而当时却没能给你你最需要的支持，甚至还幼稚地责怪你太感性。想变成小松鼠，爬到当时那颗我们吵架的树上，跳到你肩膀上，跟你说句“宝贝，辛苦了”。

想到你一次次略显失落地看着那一条横线，一次次将它放在光下用不同角度仔细寻找另一根在哪，直到那一抹甚至看起来时有时无的蓝色出现。他这样珍贵地出现，你是这样爱他，让我有一些怕他出生之后会让你疏忽了自己。可能他最爱吃脆脆的东西，但请别忘记你最爱吃糯叽叽的一切；可能他和我一样喜欢大海胜过森林，但请别忘记你更爱那郁郁葱葱的生命力；可能他开口第一句说的是“妈妈”，但请别忘记你首先是那个元气少女范雅琪。

不过话说回来，昨天去取婴儿提篮这个事让我意识到可能被裹挟的更多的居然是我，而且我自己会在没有意识到的情况下就被道德绑架了，这个让我觉得很神奇。而你会像Zion听到出门一样从好远的地方就捕捉到我的情绪，鼓励我说出自己的想法，然后和我一起感受我还没来得及好好感受的内心涟漪。你是我的一部分，最好的那一部分。

> Baby, the best part of me is you <br>
> And lately, everything's making sense too <br>
> Oh, baby, I'm so in love with you

等待那抹蓝的这年，我们两个第一次一起开始学习并爱上一项运动；第一次穿着救生衣真正进入我爱的大海，而不是只在岸边；第一次手牵手去海里看成群结队的鱼，一起发出呜呜的惊叹声；第一次看地球心脏跳动，一起被震撼到失神；第一次和爸爸妈妈们候鸟迁移，和最爱的家人一起生活；第一次一起到欧洲，去你当时不喜欢的城市，发现彼时未曾感受到的美好与善意，看到你喜欢的选手夺得大满贯。这是我爱的你，这个不会游泳也要去冲浪的你，这个看到哪怕只是一抹葱绿就会开心哇出来的你，这个去到一个陌生城市总是想要走遍每一个角落，把所有好吃的装进肚子的你。

想亲亲你的肚子，告诉你我多么爱你，体会大自然的神奇，一个生命居然是这样慢慢被另一个生命孕育；想将你举高然后和你一起旋转，看你开心地大笑，一个生命居然是这样慢慢被另一个生命陶醉。最近特别喜欢早上的时光，因为起来后可以打网球，而打网球时你的笑容格外灿烂。那笑很有感染力，我看到后有时会失神，一瞬间忘记所有烦恼，只感恩生活让我可以感受到这样纯粹的快乐和安稳。谢谢你，我在这个世界上最大的快乐，二十九岁生日快乐。

<script>
(function () {
  var opened = false;

  window.openGiftBox = function () {
    if (opened) return;
    opened = true;
    launchConfetti();
    setTimeout(function () {
      var c = document.getElementById('gift-container');
      c.style.opacity = '0';
      c.style.transform = 'scale(0.85)';
      setTimeout(function () {
        c.style.display = 'none';
        document.getElementById('gift-reveal').style.display = 'block';
      }, 400);
    }, 1000);
    setTimeout(stopConfetti, 5500);
  };

  function launchConfetti() {
    var canvas = document.getElementById('confetti-canvas');
    canvas.style.display = 'block';
    canvas.width = window.innerWidth;
    canvas.height = window.innerHeight;
    var ctx = canvas.getContext('2d');
    var COLORS = ['#f39c12','#e74c3c','#3498db','#2ecc71','#9b59b6','#fff','#fd79a8','#fdcb6e'];
    var particles = [];

    function burst(ox, oy, n) {
      for (var i = 0; i < n; i++) {
        var a = Math.random() * Math.PI * 2;
        var s = Math.random() * 12 + 4;
        particles.push({
          x: ox, y: oy,
          vx: Math.cos(a) * s,
          vy: Math.sin(a) * s - Math.random() * 6,
          color: COLORS[Math.floor(Math.random() * COLORS.length)],
          w: Math.random() * 10 + 4,
          h: Math.random() * 6 + 3,
          rot: Math.random() * 360,
          rotV: (Math.random() - 0.5) * 12,
          gravity: 0.28, drag: 0.97,
          opacity: 1,
          circle: Math.random() > 0.65
        });
      }
    }

    var box = document.querySelector('.gift-anim').getBoundingClientRect();
    var cx = box.left + box.width / 2;
    var cy = box.top + box.height / 3;
    burst(cx, cy, 120);
    setTimeout(function () { burst(cx - 90, cy - 50, 60); }, 300);
    setTimeout(function () { burst(cx + 90, cy - 60, 60); }, 500);
    setTimeout(function () { burst(cx, cy - 90, 70); }, 700);

    var raf;
    function draw() {
      ctx.clearRect(0, 0, canvas.width, canvas.height);
      var alive = false;
      for (var i = 0; i < particles.length; i++) {
        var p = particles[i];
        p.x += p.vx; p.y += p.vy;
        p.vx *= p.drag; p.vy *= p.drag;
        p.vy += p.gravity;
        p.rot += p.rotV;
        p.opacity -= 0.011;
        if (p.opacity <= 0) continue;
        alive = true;
        ctx.save();
        ctx.globalAlpha = p.opacity;
        ctx.translate(p.x, p.y);
        ctx.rotate(p.rot * Math.PI / 180);
        ctx.fillStyle = p.color;
        if (p.circle) {
          ctx.beginPath(); ctx.arc(0, 0, p.w / 2, 0, Math.PI * 2); ctx.fill();
        } else {
          ctx.fillRect(-p.w / 2, -p.h / 2, p.w, p.h);
        }
        ctx.restore();
      }
      if (alive) { raf = requestAnimationFrame(draw); } else { stopConfetti(); }
    }
    window._giftRaf = raf = requestAnimationFrame(draw);
    window._giftCtx = ctx;
  }

  function stopConfetti() {
    if (window._giftRaf) cancelAnimationFrame(window._giftRaf);
    var canvas = document.getElementById('confetti-canvas');
    if (canvas && window._giftCtx) window._giftCtx.clearRect(0, 0, canvas.width, canvas.height);
    if (canvas) canvas.style.display = 'none';
  }
})();
</script>
