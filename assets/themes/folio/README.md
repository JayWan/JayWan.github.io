# 笺（folio）

把这些信做成一本书。首页是竖排的目录，一年一叶，自右向左读；点开是一张横格信笺，字落在格线上。
纸、墨、一点朱。没有印章，没有水墨，没有纹理，没有动效。

**界面上没有说明文字。** 怎么读由版面自己交代：年表、下栏的日数、空着的行、折角、色标、剪刀线。
界面上的字只有四种：题名和名字、日期和数字（带一两个字的标签，如「日数」「相识」）、一两个字的去处（「目录」「上一封」）、
网站自己的那句话。给读屏的话写在 `aria-label` 里，一样也不少。要加东西时先想能不能画出来。

## 首页：目录

- **扉页**：右起是书名、「书信集」（几封、起止年份、两个人各写了几封）、年表、最近的一封。
- **次序**：默认新的在前，最新的一封领头。最新的一年是第一叶，一叶之内也是新的在前：整本书从右读到左、
  从头读到尾是一条不回头的线，下栏的日数一路变小（要是只把年份倒过来、年内照旧，读起来就是来回折的）。
  年份索引最前面有一个记号，一支箭加三道由长到短的线，点一下换成旧的在前，记号整个倒过来；
  年份索引、年表、每一叶都跟着换。跋不在他们俩的次序里，哪种排法都在书末。
  选过的次序只记这一次到访（`sessionStorage` 里的 `f221:sort`）。信里的「上一封 / 下一封」和第几封不跟着变，
  永远按写信的先后。记号没有字，读屏读到的是「信的次序：最新的在前 / 最早的在前」。
- **年表**（`chart()`）：这本书的缩样，也是原来「凡例」要说的话。一年一行；一行里的走向和下面每一叶一样：
  旧的在前时一月在右、十二月在左，最早的一年在上；新的在前时左右、上下都对调（十二月在右，最新的一年在上）。
  一封信一道竖线，线上空着的地方就是没写信的日子，没有信的年份是一条空线。
  横线从相识那天画起，起点上印着朱色的 0，画到今天为止，终点上印着今天的日数：
  下栏里那些朱色的数字是什么，看这两头就知道了。最后一道竖线之后还空着的那一段，就是「下一封还没写」。
  这两个数字印在线头的正上方；线头离一年的两端太近时（一月初、十二月底），数字停在刻度的尽头，不压到格线和年份上。
  年表只是一张图（`role="img"`），不能点；屏宽不到 350px 时不印。
- **年份索引**：扉页下面的一行年份（跟着次序排，跋总在最后），点了跳到那一叶；没有标签，读屏读到的是「去哪一年」。
  跋只有一篇时，「跋」直接打开它（这样最新的一封离第一屏只有一下）。
- **一叶**：年份占一列，其后每封信一列，剩下的列空着，空白也是内容。一列里有：题名、
  夹注（日期、执笔、《配歌》）、一道虚线、下栏里的日数（页码的位置上印的是相识以来的天数）。
- **眉批**：每一排上边的空白处印一句从信里摘的话（朱色）。桌面上指到哪一列就换成哪一列的；
  刚读完一封信回到目录，印的是那一封的，那一列也亮着。
- 信少的年份两叶并排（各占半宽）；没有信的年份照样有一叶，写着「没有信」。
- 客人写的信不进年份，放在书末的一小叶「跋」里。
- 触屏上点一下就展信，没有预览这一步。

## 读信：笺

- 笺头印着「221 FOREVER 用笺」和汉字的日期。正文的行高就是格距，段落、歌词、图、卡片都占整数行
  （图和卡片的高度由脚本补成整行，见 `snap()`）。
- 右边的书口竖排题名和题记；左边是图版（封面）、配歌和播放键、执笔与日数。窄屏上这些排在正文前面。
- **图**：信里的图都是原来的颜色，带一圈衬纸，宽度随图。只有封面图版会印成墨色，而且只在它是网上找来的图时
  （`cover.own === false`）；点一下换成原色。图注右边的三个圈是色标：墨色时是空的，原色时套上青、品红、黄。
- **加粗**：仿宋没有粗体。几个字的加粗改成朱色着重号；整段都是加粗的（第 12 封里她写的那些行）在段落左边画一道朱线。
- **落款**：信末的日期、地点靠右、淡墨。两头带一长串横线的落款（「One Year」的最后两行）把横线画成两道短线，
  字本身不动，窄屏上才不会折行。
- **两封特别的信**：翻转卡片直接换面，不转，右下角折着一个角（背面是同一个角，所以在左下）；
  礼物盒外面一圈朱色的虚线，线上一把剪刀，照常拆开、撒彩纸，拆出来的图不浮动。
- **信末**：上一封 | 目录 | 下一封，是和目录同一套格子的一小叶。上一封在右边，因为书往左翻。
  「目录」下面的小字是会回到的那一叶。第一封的右边只印「第一封」；最后一封的左边是一列空白，一道虚线接着往下。
- **歌**：一个圆形的播放键，从不自动播放。窄屏读信时屏幕底边一直有一行：播放键、歌名、时间、「目录」。
  歌放着的时候这一行在哪一页都在。
- 沉重的信（`quiet`）页脚不出现网站自己的那句话。

## 换主题

入口是 `ctx.ui.switcher()`（规矩见 `../README.md`），每一页一个，都在右上角、离页顶一样远，读者从目录到信到缺页，它不挪地方。
页脚和信末不再有主题的名字；页脚以版权那一行收尾。

- **收着**：这套的名字「笺」和一道小折线（画在按钮里那个空的 `<i>` 上，一个直角的两条细边），淡墨，没有框。
  点开以后名字变成墨色，折线翻过来朝上。可点的范围至少 44 × 44px，名字的右边和版框的右边对齐。
- **点开**：按钮下面一小叶竖排的名字，自右向左（第一个「旧版」在最右边，挨着按钮），和目录同一种格子：
  上沿一道粗的版框线，列与列之间是界行，纸比页面亮一点。身上穿的这一套是墨色，左边一道朱线：这是竖排里的专名号，
  也就是信里整段加粗时画在左边的那道朱线，不只靠颜色。
  按钮和这一小叶都没有写死的高度和宽度（行高不带单位），字被浏览器放大时跟着长，一列还是装得下两个字。
- **在哪里**：目录在扉页上面天头的右上角（扉页从右边读起，它是第一样，Tab 也先到它）；信在顶上那一行的右端，
  「31 / 32」后面隔一道短界行；缺页和目录同一个位置，点开的那一小叶上沿正好压在缺页的版框上，两道线合成一道
  （所以缺页的版框在哪种屏幕上都在页顶下 68px）。
- **信的顶上那一行**：目录 | 书名 | 第几封、入口。桌面上书名居中；手机上三样之间的空白一样宽（至少 20px），
  挤了书名先在空格处折成「221 / FOREVER」两行（375、360px 宽的手机），还放不下（320px，或者字放大了）就另起一行，
  排在下面居中，这一行跟着长高。哪种排法是 `fitBar()` 量出来的（入口伸出了这一行的右边就让书名下去），不按屏宽猜。
- 目录画一次就一直留着：在目录上开着列表、用浏览器的「前进」「后退」走开再回来，列表是收着的（`show()` 开头用它自己的按钮关上）。

## 文字被浏览器放大

有的浏览器可以只放大文字（Firefox 的「仅缩放文本」、Safari 的「仅缩放文字」、系统的文字大小设置）：字大了，
写成 px 的行高跟着大，盒子、留白、图都不变。这个主题的版面是按像素定的（一格装几个字、天头放十个字、行高等于格距），
放大到 120% 眉批就顶到年份索引上，书名伸出格子，信里的格线从字中间穿过去。所以主题自己跟着量：

- **量，不猜。** 页面里有一个看不见的 16px、行高 1 的「日」（`.fo-probe`）。`rescale()` 量它实际排出来多高，除以 16 就是倍数，
  写在 `#theme-root` 上（`--ts` 和 `data-ts`）；它的大小一变（读者在页面上调了缩放）就重量、重排。只量高：和字体无关。
  倍数是 1 时什么都不写：版面和没有这回事时一个像素都不差（和改之前的截图逐像素比过）。量不到（盒子是 0）也当作 1。
- **首页**：格高、天头、年表的行高和年份栏，这些「装得下几个字」的尺寸在 `theme.css` 里乘 `var(--ts,1)`。
  题名和夹注比一列还宽时，一叶的列数退一档（`layoutHome()` 里量出来的：12、10、8、6、5、4、3，写回 `#theme-root` 的 `--n`；
  少到五列以内就像最窄的手机一样不印年表，`data-few`）。眉批排完以后再量一遍，还伸出天头的
  （倍数量不准、换了字体、浏览器设了最小字号）一行少排几个字，直到放得下；行数多了比所在的一叶还宽的
  （手机上字放大到 150%，两年并排的半叶只有两列宽），行距收紧到放得下，不伸进旁边那一叶。
  缺页照样式表的列数排，不跟目录少排的那几列。
- **信**：浏览器把 36px 的行高放大成 43.2px，格线要跟着走；可带小数的格距哪个引擎都画不好
  （Firefox 每五道少画一道，Chrome 画虚了而且越往下越偏，WebKit 取整以后偏得更多）。所以 `pitch()` 把行距取成整数个设备像素，
  倒推出该写进 `line-height` 的值。`.letter` 上因此有三个变量：`--ld` 只用在 `line-height` 里，`--lp` 是格距和一切「占几行」的尺寸
  （留白、段距、卡片），`--sh` 是格线上移的那一点；平时它们就是设计值 `--lh` 和 `--shift`。
  **以后给正文加样式照这个分法用**：行高写 `var(--ld)`，尺寸写 `var(--lp)`，不要再用 `--lh` 量尺寸。
  图不跟着放大（仍按 `--lh` 算最大高度），照旧由 `snap()` 补成整行；格距和图高都带零头时，只多出不到 0.6px 的不补一整行，
  而是从图下面的空里扣掉这一点（否则每张图让后面的字往下偏半个像素，几张图以后就压线了）。
- 能验证的只有 Firefox（Playwright 启动它时给 `ui.textScaleFactor` 和 `browser.display.os-zoom-behavior: 2`，就是只放大文字）：
  100% 到 150%、四种屏宽量过。测试在 `tests/themes-folio.spec.mjs` 的最后一组：三条各自启动这样一个 Firefox
  （120%、150% 的桌面宽，110% 的手机宽）；眉批的「太高就少排几个字」「太宽就收紧行距」不靠放大也能测，三个引擎都跑。

## 改哪里

| 想改的 | 在哪里 |
|---|---|
| 颜色、版心宽、一叶几列、格高、天头 | `theme.css` 开头的 `:root` |
| 各个屏宽下的列数 | `theme.css` 里的几条 `@media`（`--n`）。脚本读 `--n` 来分叶，不用改脚本 |
| 扉页、年表、缺页 | `theme.js` 里的 `titleLeaf()`、`chart()`、`lostView()` |
| 次序：默认哪一种、记号的样子 | `theme.js` 里的 `oldFirst`、`inOrder()`、`setOrder()`、`SORT_SVG`；`theme.css` 的 `.sort` |
| 折角、剪刀线、色标、动图的播放记号 | `theme.css`（`.flip-card-front::after`、`#gift-container`、`.plate-mark`、`.fo-play`）；读屏的话在 `theme.js` 的 `settle()`、`plate()`、`still()` |
| 题名在哪里断成两行 | `theme.js` 开头的 `BREAKS`。没列出来的题名按标点和词界自动断 |
| 眉批、题记怎么分行 | `quoteLines()`、`splitClause()`；不该拆开而分词又认不出的词加进 `KEEP` |
| 每一排默认印哪一句眉批 | `PICKS`；没指定的排印第一封的 |
| 文字被浏览器放大时的版面 | `theme.js` 的 `rescale()`、`pitch()` 和 `layoutHome()` 里量的那几段；`theme.css` 里带 `--ts`、`data-ts`、`data-few`、`--ld` / `--lp` / `--sh` 的规则 |
| 换主题的入口 | `theme.js` 里三处 `ui.switcher()`（`homeView()`、`letterView()` 的 `.bar-r`、`lostView()`）；样式在 `theme.css` 的 `.theme-switcher` 那一段，离页顶多远是 `.home` 的 `--sw`；信的顶上那一行在 `.bar`、`.is-two` 和 `theme.js` 的 `fitBar()` |

## 几件要知道的事

- 回目录、上一封 / 下一封都是普通链接，历史记录和「回到刚读的那一封」由核心负责
  （`data-back`、`router.lastRead`）。主题只负责把那一列标出来（`.is-read`）。
- 「去哪一年」是页内的锚点，浏览器会为它记一条历史。核心关掉了浏览器自己的滚动恢复，所以主题在 `hashchange` 里
  自己滚：后退回到出发的位置，前进回到那一叶。
- 手机上年份索引一行七格：次序的记号、十二个年份、跋，现在正好两行。再多一年就多出一行，
  那时把 `.yidx` 的格数改成八（`theme.css` 的窄屏部分）。
- 首页上出现的字决定首屏要下载多少字体。改了首页上的字以后，按 `assets/fonts/README.md` 重新生成一次字体，
  否则一个不在首屏切片里的字就可能多下一百多 KB。
- 正文两端对齐。`text-wrap: pretty`（段末不留孤字）只给 Chrome：WebKit 下它会让每一行早断三四个字，
  右边空出一条。`theme.css` 里用 `hanging-punctuation` 把 WebKit 分出来，改这一行前先在 Safari 里看一眼。
- 读者要求少动时，信里的动图停在第一帧，下面印一个朱色的播放记号（动起来以后是暂停），点它和点图一样；
  这一行在排版时就占好了位置。
- 年表的行高用 CSS 的 `round()` 取成奇数个整像素，横线才落在像素上；不认识 `round()` 的浏览器（Chrome 124 及以前，
  包括一些内嵌浏览器）平分高度，线略虚一点。这条规则必须留在 `@supports` 里：值里带着 `var()`，
  不认识 `round()` 的浏览器不会跳过它，而是把行高算成 `auto`，十几行就塌成一团。
  一年多一行，行就矮一点：到十五六行（2028、2029 年）线头上的日数会碰到上一行的竖线，「0」会碰到月份刻度，
  那时把 `.nb-d` 挪到线头的旁边或者改小；到二十行上下（2033 年前后）手机上年份也挤了，把年份标签改成隔年印。
- 朱雀仿宋只有一个字重，也没有斜体，所以 `font-synthesis: none`；西文和数字用 Garamond。
- 测试：`npx playwright test -g 'theme "folio"'`（所有主题共同的约定）和 `tests/themes-folio.spec.mjs`（这个主题自己的承诺）。
  换主题的入口共同的规矩在 `tests/switcher.spec.mjs`；这个主题自己的几条在 `themes-folio.spec.mjs` 的「the way to another theme」：
  402、375、360、320px 宽的手机上信的顶上那一行四样不挨着、不出屏、入口在最右（402px 时书名不折行）；入口在目录、信、缺页上是同一个位置；
  缺页上点开的那一小叶压在版框上；在目录上开着的列表走开再回来是收着的。字放大的那三条也查顶上那一行。
