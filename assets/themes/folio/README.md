# 笺（folio）

把这些信做成一本书。首页是竖排的目录，一年一叶，自右向左读；点开是一张横格信笺，字落在格线上。
纸、墨、一点朱。没有印章，没有水墨，没有纹理，没有动效。

**界面上没有说明文字。** 怎么读由版面自己交代：年表、下栏的日数、空着的行、折角、色标、剪刀线。
界面上的字只有四种：题名和名字、日期和数字（带一两个字的标签，如「日数」「相识」）、一两个字的去处（「目录」「上一封」）、
网站自己的那句话。给读屏的话写在 `aria-label` 里，一样也不少。要加东西时先想能不能画出来。

## 首页：目录

- **扉页**：右起是书名、「书信集」（几封、起止年份、两个人各写了几封）、年表、最近的一封。
- **年表**（`chart()`）：这本书的缩样，也是原来「凡例」要说的话。一年一行，自上而下；一行里一月在右、十二月在左，
  和下面每一叶的走向一样；一封信一道竖线，线上空着的地方就是没写信的日子，没有信的年份是一条空线。
  横线从相识那天画起，起点上印着朱色的 0，画到今天为止，终点上印着今天的日数：
  下栏里那些朱色的数字是什么，看这两头就知道了。最后一道竖线之后还空着的那一段，就是「下一封还没写」。
  这两个数字印在线头的正上方；线头离一年的两端太近时（一月初、十二月底），数字停在刻度的尽头，不压到格线和年份上。
  年表只是一张图（`role="img"`），不能点；屏宽不到 350px 时不印。
- **年份索引**：扉页下面的一行年份，点了跳到那一叶；没有标签，读屏读到的是「去哪一年」。
  跋只有一篇时，「跋」直接打开它（这样最新的一封离第一屏只有一下）。
- **一叶**：年份占一列，其后每封信一列，剩下的列空着，空白也是内容。一列里有：题名、
  夹注（日期、执笔、《配歌》）、一道虚线、下栏里的日数（页码的位置上印的是相识以来的天数）。
- **眉批**：每一排上边的空白处印一句从信里摘的话（朱色）。桌面上指到哪一列就换成哪一列的；
  刚读完一封信回到目录，印的是那一封的，那一列也亮着。
- 信少的年份两叶并排（各占半宽）；没有信的年份照样有一叶，写着「没有信」。
- 客人写的信不进年份，放在书末的一小叶「跋」里。
- 触屏上点一下就展信，没有预览这一步。

## 读信：笺

- 笺头印着「221 FOREVER 用笺」和汉字的日期。正文的行高就是格距，段落、歌词、图、卡片都占整数行
  （图和卡片的高度由脚本补成整行，见 `snap()`）。
- 右边的书口竖排题名和题记；左边是图版（封面）、配歌和播放键、执笔与日数。窄屏上这些排在正文前面。
- **图**：信里的图都是原来的颜色，带一圈衬纸，宽度随图。只有封面图版会印成墨色，而且只在它是网上找来的图时
  （`cover.own === false`）；点一下换成原色。图注右边的三个圈是色标：墨色时是空的，原色时套上青、品红、黄。
- **加粗**：仿宋没有粗体。几个字的加粗改成朱色着重号；整段都是加粗的（第 12 封里她写的那些行）在段落左边画一道朱线。
- **落款**：信末的日期、地点靠右、淡墨。两头带一长串横线的落款（「One Year」的最后两行）把横线画成两道短线，
  字本身不动，窄屏上才不会折行。
- **两封特别的信**：翻转卡片直接换面，不转，右下角折着一个角（背面是同一个角，所以在左下）；
  礼物盒外面一圈朱色的虚线，线上一把剪刀，照常拆开、撒彩纸，拆出来的图不浮动。
- **信末**：上一封 | 目录 | 下一封，是和目录同一套格子的一小叶。上一封在右边，因为书往左翻。
  「目录」下面的小字是会回到的那一叶。第一封的右边只印「第一封」；最后一封的左边是一列空白，一道虚线接着往下。
- **歌**：一个圆形的播放键，从不自动播放。窄屏读信时屏幕底边一直有一行：播放键、歌名、时间、「目录」。
  歌放着的时候这一行在哪一页都在。
- 沉重的信（`quiet`）页脚不出现网站自己的那句话。

## 改哪里

| 想改的 | 在哪里 |
|---|---|
| 颜色、版心宽、一叶几列、格高、天头 | `theme.css` 开头的 `:root` |
| 各个屏宽下的列数 | `theme.css` 里的几条 `@media`（`--n`）。脚本读 `--n` 来分叶，不用改脚本 |
| 扉页、年表、缺页 | `theme.js` 里的 `titleLeaf()`、`chart()`、`lostView()` |
| 折角、剪刀线、色标、动图的播放记号 | `theme.css`（`.flip-card-front::after`、`#gift-container`、`.plate-mark`、`.fo-play`）；读屏的话在 `theme.js` 的 `settle()`、`plate()`、`still()` |
| 题名在哪里断成两行 | `theme.js` 开头的 `BREAKS`。没列出来的题名按标点和词界自动断 |
| 眉批、题记怎么分行 | `quoteLines()`、`splitClause()`；不该拆开而分词又认不出的词加进 `KEEP` |
| 每一排默认印哪一句眉批 | `PICKS`；没指定的排印第一封的 |

## 几件要知道的事

- 回目录、上一封 / 下一封都是普通链接，历史记录和「回到刚读的那一封」由核心负责
  （`data-back`、`router.lastRead`）。主题只负责把那一列标出来（`.is-read`）。
- 「去哪一年」是页内的锚点，浏览器会为它记一条历史。核心关掉了浏览器自己的滚动恢复，所以主题在 `hashchange` 里
  自己滚：后退回到出发的位置，前进回到那一叶。
- 首页上出现的字决定首屏要下载多少字体。改了首页上的字以后，按 `assets/fonts/README.md` 重新生成一次字体，
  否则一个不在首屏切片里的字就可能多下一百多 KB。
- 正文两端对齐。`text-wrap: pretty`（段末不留孤字）只给 Chrome：WebKit 下它会让每一行早断三四个字，
  右边空出一条。`theme.css` 里用 `hanging-punctuation` 把 WebKit 分出来，改这一行前先在 Safari 里看一眼。
- 读者要求少动时，信里的动图停在第一帧，下面印一个朱色的播放记号（动起来以后是暂停），点它和点图一样；
  这一行在排版时就占好了位置。
- 年表的行高用 CSS 的 `round()` 取成奇数个整像素，横线才落在像素上；不认识 `round()` 的浏览器（Chrome 124 及以前，
  包括一些内嵌浏览器）平分高度，线略虚一点。这条规则必须留在 `@supports` 里：值里带着 `var()`，
  不认识 `round()` 的浏览器不会跳过它，而是把行高算成 `auto`，十几行就塌成一团。
  一年多一行，行就矮一点：到十五六行（2028、2029 年）线头上的日数会碰到上一行的竖线，「0」会碰到月份刻度，
  那时把 `.nb-d` 挪到线头的旁边或者改小；到二十行上下（2033 年前后）手机上年份也挤了，把年份标签改成隔年印。
- 朱雀仿宋只有一个字重，也没有斜体，所以 `font-synthesis: none`；西文和数字用 Garamond。
- 测试：`npx playwright test -g 'theme "folio"'`（所有主题共同的约定）和 `tests/themes-folio.spec.mjs`（这个主题自己的承诺）。
