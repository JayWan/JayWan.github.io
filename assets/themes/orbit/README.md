# 绕日（orbit）

把所有的信画成一张日心轨道图版：一年一圈，一封信一个天体，旁边是一张星历表。
出处是第 29 封信的标题「你我同绕日，十度春秋」和信里那句「撞出了春夏秋冬」。

## 图怎么读

- 角度是那一天地球的日心黄经，自黄道北极俯视，逆时针前进；冬至在正上方。
- 一年一环，最早的一年在最外面。认识之前、今天之后的弧是虚线。
- 外圈是日历尺：一天一格，一月一条分界。十字轴是二分二至。
- 五条径向虚线是每年都会经过的五个日子（认识、在一起、结婚、两个生日）。
- 记号：实心点 = 他，空心圈 = 她，半实 = 合写，带尾巴的小天体 = 访客，⊕ = 今日。图例里每一个都有说明。
- 琥珀色只给三样东西：太阳、被选中的信（和它自上一封以来走过的弧）、正在播放的进度。
  两封信隔得越久，弧越长；第 22 封之前的 838 天是两圈多。

## 只说轨道上的话

T+（自认识那天起的整日数）、圈次和度数（自在一起那天起算，之前是「入轨前」）、距上一封多少天。
「季节」的大字是 `ctx.ui.fmt.season` 给的按月份的春夏秋冬，小字是离最近的二分二至几天（按日历天数）。
没有信的年份写「没有信」。

## 版式

| 宽度 | 样子 |
|---|---|
| ≥ 1400px | 一张带双线框的图版：左图右表，高度够（≥ 835px）时一屏放完，不够时图版保持 760px 高，页面可以滚 |
| 1200 – 1399px | 同样左图右表，站名和图注不再压在图的四角上，各占一行 |
| < 1200px | 自上而下：图、读数栏、星历表、图例。点图上任何地方会落到最近的一封信上 |
| ≥ 1200px 的触屏 | 星历表每行至少 44px |

信的页面：题头、数据条、定位图、这封信的歌、正文。桌面上封面在右栏，第一行正文不用滚就能看到；
手机上数据条变成清单，定位图在它右边。结尾是 `T+N d`、逆行 / 顺行、回到绕日图。
题目用多大的字看它有多宽（西文字母算半个多一点的汉字），不是看字数。

## 读数栏

图下面那一栏平时是今日读数；选中一封信（指针移上去、键盘聚焦、手机上点图）就读出那封信。

- 桌面上它的高度是定死的（图不能跟着跳），但题目和歌名从不截断：题目排成两行就小一号、摘句只留一行；
  还放不下，摘句不放（`theme.js` 里的 `fit()`）。1400px 以下不放缩略图。
- 选中只跟着**真的动了**的指针走。页面在不动的指针底下换了内容时，浏览器会补发 `pointerenter`
  （WebKit 还补发坐标不变的 `pointermove`）；那不算数，不然从信里回来，碰巧停着指针的那一行会把刚读过的那封换掉。
- 回到图上时选中的是刚读过的那一封（`router.lastRead`）；「今日」或 Esc 回到今日读数。

## 照片

封面和信里的每一张照片是同一个做法：发丝线版框，默认蓝晒，图注里有「原色」，点图也可以切换。
封面不是他们自己照片的（`cover.own === false`，早年从网上找的配图）版框小一号，图注写「封面配图」。
选择记在 `localStorage` 的 `f221:orbit:colour` 里。蓝晒是纯 CSS（灰度滤镜加两层混合），滤镜只加在图片自己身上，
正文的祖先没有任何 `filter` / `transform`。卡片背面那张手写的照片也在版框里；礼物盒没打开时是蓝晒，打开后是原色。

## 歌

信页上有一行「这封信的歌」（桌面上滚动时吸在顶部）。歌一旦响起，屏幕底部出现一条「正在播放」，
暂停键在拇指够得着的地方，换页也不会断。进度点绕着播放键逆时针公转。

## 动效

开页时信按时间顺序出现一次；选中时画出那段弧；今日记号有一圈很慢的涟漪；播放时进度在走。
`prefers-reduced-motion: reduce` 时全部静止。

## 字

界面上的字尽量只用字体切片 a 里已有的字（`scripts/fonts.py --check` 会说哪些不在）。现在首页上只有图例里的「访客」两个字不在，
多下载两个切片（约 131 KB），等字体在合并时重新生成就没有了。改界面文案之后记得重跑字体脚本。

## 文件

- `theme.css`（≤ 40 KB）、`theme.js`（≤ 60 KB），没有别的资源，图标都是内联 SVG。
- 字体：登记表里的 `serif-sc`、`text`。
- 测试：`tests/themes-orbit.spec.mjs`（共用的那一套在 `tests/themes.spec.mjs`）。
