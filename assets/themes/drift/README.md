# 夜航（drift）

夜里的一条时间的河。相片按写信的日子漂在时间轴的两岸，点一张，它的白边就地长成一张信纸。
这是「基于时间线和照片的浮动网页，书信可展开」那个想法的正式版。11 月 28 日（认识的那天）一定是它。

## 它是什么样的

- **最新的在最上面。** 打开就是最近的一封，往下滚是回头看；整页最后一样东西是源头的那盏灯「2015.11.28 认识」。
- **三层远近。** 近处的相片最大（桌面上约 540px），远处的最小（约 240px，更暗、略虚），至少差 2.2 倍；相片可以略微压住轴线和彼此。手机上只有一岸，远近变成宽窄。
- **每张相片下面都有这封信的一句话**（摘句，每次打开随机换一句），远近三层都有，越远字越小一点；没有封面的信，那句话印在纸上。
- **网上找来的图不算他们的相片。** `cover.own === false` 的封面永远在最远一层：小、暗、没有纸边；打开信之后题图也只是小小一张。他们自己的照片和画才有纸边，才会上近处。客人写的信（第 32 封）也在远处，标着「Claude 写的」。
- **谁写的，每一张都标。** 日期、认识第几天、笔名，三十二张一个写法，没有谁是例外。两个人合写的那封是「Pikajay 和 Pikachi」。
- **空白照实留着。** 超过 180 天没写信，轴线变成虚线，中间只有一个数字；空出来的长度和天数成正比，所以 838 天那一段是整页最长的空白（桌面约 850px，手机约 575px）。一年以内只写数字，更长的才写「没有信 / 2020 年一封也没有」。
- **只有一种亮色：纸。** 相片的白边、信纸、三盏灯（认识、在一起、结婚）和「今天」都是同一种纸白，没有第二种强调色。
- **界面不写说明。** 怎么读、点哪里、颜色和位置是什么意思，都不用句子讲，让形状自己说：题头下面那条小刻度、相片的浮起、实心的播放键。界面上留下的字只有名字、日期、数字和它们的短标签，一两个词的导航，和几个字的状态（「没有了」「还没写」「没放出来」「404 没有信」）。
- **题头**只有三样：站名、三个天数（认识 / 在一起 / 结婚，截至今天）、一条小刻度。小刻度是整条河横过来的缩影：从认识那天到今天等比例的一条线，一封信一道竖线，超过 180 天没写信的那几段是虚线，下面是年份，今天那一头亮着一盏灯。它替以前的两句话交代了「十一年、三十二封、哪几年挤、哪几年空、哪头是现在」。手机上不画它，底栏的时间刻度就是同一样东西。每封信的信头里是写信那天的三个数，没到的日子写「还没有」。
- **相片会被拿起来。** 桌面上悬停时浮起；刚到首页时，第一屏里最近的那张自己浮起一次再落下（系统要求减少动效或关了「漂浮」时不做）。
- **时间刻度。** 桌面在右边，手机在底部。它是等比例的，所以 2016–17 挤成一团、2019–22 几乎是空的。手指按下去不会动；顺着刻度拖才是拖动，轻点一下跳到最近的那封，并给一个「回到刚才」。
- **信在原地展开。** 河一直在，信纸出现在那张相片的位置。信开着的时候，信纸以外的东西都暗下去；题头在河上方时（1100px 以下，包括手机）也只是变暗，不拿走，否则从最新一封往回滚会看到一整屏空白。题头在河旁边时（1100px 以上）信纸会压在它上面，那时才把它拿走。合上（顶上和信末各有一个「合上 ×」，写法相同；手机底栏、Esc、后退也行）回到刚读完的那封信的相片旁。往下读过了信尾，河立刻恢复亮度，等滚动停下来信纸自己收起，页面不跳。直接打开某封信的网址，看到的是同一张信纸，位置也在河里它该在的地方。
- **换主题在右上角。** 顶栏最右边是当前这套的名字「夜航」和一个小折角，点一下，下面垂下一小条夜色：一根竖线串着几个点，是缩小了的河，每套主题一个空心的圈，身上穿的这套是一盏亮着的灯（和「今天」「认识」是同一盏）。信开着的时候顶栏收起来了，所以信纸自己的顶栏里也有一个，在「合上」的左边，墨色，比「合上」轻；垂下来的还是那条夜色，在那里换，人还在这封信。同一时刻屏幕上只有一个；页脚和信尾不再有主题的名字。
- **顶栏只有一行。** 站名、最新一封、漂浮、夜航，三个词同一个字号（13px；「漂浮」以前被按钮的样式重置撑成了 16px，比旁边大一号，现在和样式里写的一致）。手机上靠收紧字距和间隔，窄到 320px 四样都在；再放不下（读者把字放大了，或者屏幕比手机还窄），站名整个让开，不会被切掉一半，也不会和别的字撞上。信纸的顶栏也是一行（编号、夜航、合上），放不下时让开的是编号。
- **歌。** 每封信一首，点一下才响，放完就停。播放键在信头，是信纸上唯一实心的东西，旁边不写提示，只有这首歌的长度（放起来以后是进度）；没放出来的时候它变成一圈虚线，旁边四个字「没放出来」，再按就是重试。滚走以后，桌面的信纸顶栏里有一个小的，手机底栏里一直有一个（拇指够得到）。合上信歌不停，回到河里还能暂停。
- **两封特别的信。** 礼物盒点了才开，彩纸铺满整屏；翻转卡片点一下翻面，卡片两面的角上各有一行小字（「背面 →」「← 正面」；正面那行和信里自己的落款小字排在同一行，卡片不会因此变高），因为信里没有别的地方告诉读者它能翻。
- **键盘。** Tab 能走到每一张相片，Enter 打开；信开着的时候 Tab 只在这封信自己的控件里转（换主题、合上、播放、进度、卡片、上一封 / 下一封），←/→ 翻信，Home / End 是这封信的头和尾，Esc 合上并把焦点还给那张相片。主题的列表开着的时候，Esc 只关列表，信不合上；焦点在列表里时 ←/→ 也不翻信。
- **标题和摘句在标点后面换行**（「装修好了，／钥匙在门垫下面」），不会把一个词拆成两半。
- **沉重的那封**（`quiet`）不漂、不歪、悬停不放大、展开没有动画。
- `prefers-reduced-motion` 下全部静止；顶栏里的「漂浮 开/关」会记住。

## 文件

| 文件 | 内容 |
|---|---|
| `theme.css` | 全部样式。颜色和字体栈在最上面的 `:root` 里 |
| `theme.js` | 一个 `mount(ctx)`：搭页面、算河的版式、时间刻度、信纸的开合、播放界面 |
| `grain-light.png` / `grain-dark.png` | 两张 180px 的颗粒纹理（整页一层，相片白边一层）。4 位调色板 PNG，一共 25 KB；重新导出时保持这个格式 |

字体只用登记表里的 `serif-sc` 和 `mono`（标签和数字）。`sans-sc-400` 这个主题没有用到，可以从 `_data/themes.yml` 里去掉。

## 要改什么，去哪里改

- **颜色、字体**：`theme.css` 开头的 `:root`。底色要和 `_data/themes.yml` 里的 `ground` 一致。
- **空白有多长**：`theme.js` 开头的 `clear()`（桌面）和 `clearPhone()`（手机）；多少天算「空白」是 `SILENCE`。普通两封之间的距离是 `step()`。
- **哪张相片在哪一层**：`theme.js` 里的 `LAYER`。规则是：找来的图、客人的信、没有封面的信在远处；沉重的信、原图太小的在中间；其余在近处，最多连着两张。
- **相片多大、离轴多远**：`solveDesk()` 里的 `wz`（三层的宽度）和 `guts`；手机是 `solvePhone()`。
- **界面上的字**：都在 `theme.js` 里，搜中文即可（翻转卡片角上的「背面 →」「← 正面」在 `theme.css`）。加字之前先想能不能画出来；不要加解释页面怎么用的句子。网站自己说的那句话来自 `ctx.ui.hunger()`，不要改写。
- **题头的小刻度**：`theme.js` 里的 `strip`，样式是 `theme.css` 的 `.strip`。
- **换主题的入口**：`theme.js` 里有两处 `ui.switcher()`，一处在顶栏 `bar` 的末尾，一处在信纸顶栏 `S.bar` 里「合上」的前面；开合由核心管，主题只管画。样式是 `theme.css` 里 `.theme-switcher` 那一段（列表在纸上也是夜色，所以只有按钮在信纸顶栏里换成墨色）。窄手机上顶栏怎么收紧，在文件末尾 `max-width: 369px` 和 `359px` 那两段；站名和信的编号放不下时让开的写法在手机那一段的 `.brand, .sb-no`。`theme.css` 离 40 KB 的上限只剩二十几个字节，加样式之前先腾地方。
- **信的正文排版**：`theme.css` 里 `.letter-body` 那一段。信里的照片在加载之前就按自己的尺寸占好了位置（`fillSheet()` 把 `width` / `height` 属性写成 `--w`、`--r`），所以一封信从打开起就是它完整的长度。
- **相片要多清楚的图**：`setWidth()`。近处和中间的相片最多要 2 倍图，远处的最多 1.6 倍，而且河里的相片不要宽过 800px 的图（打开信以后，题图才按屏幕的清晰度来）。首页首屏因此在手机和 2 倍屏的桌面上都留有余量。

## 测试

`tests/themes-drift.spec.mjs` 记着这个主题自己的承诺：远近和找来的图、每张相片都带一句摘句、空白成比例、刻度按下不动、读过信尾自己合上且不跳（之后按前进，信从头打开）、合上回到刚读的那封、上一封 / 下一封之后后退一步回到河里、信的开头在第一屏、信开着时 Tab 不离开这封信、换主题的入口（河上在顶栏末尾，信开着时在信纸顶栏里「合上」的左边，一屏只有一个，页脚和信尾没有；列表是夜色、当前这套是灯；列表开着时 Esc 只关列表；Tab 走得到入口和每个名字；在那里换还留在这封信）、402 / 375 / 360 / 320px 宽的手机上两条顶栏各自排在一行（不切、不叠、列表在屏幕之内）、顶栏放不下站名时站名整个让开、信开着时河上方的题头只变暗不消失、信里的照片加载前就占好位置、进度线整条都点得到、标题在逗号后换行、客人的落款只有日期。通用的检查在 `tests/themes.spec.mjs`。

## 知道但没做的

- 第 6 封「Hang Zhou」在河里仍是那张找来的球鞋图（在远处、没有纸边）。信里有四张他们自己的杭州照片，但 `ctx` 不提供信内图片的数据，主题不能自己拼图片地址。要换，在这封信的 front matter 里把封面换成自己的照片即可。
- 信是在河里原地展开的，所以信的页面不是从文档顶端开始的。iOS 上点状态栏「回到顶部」时，主题会把读者送回这封信的开头（判断方法：这次滚动不是手指带起来的，信纸离开屏幕一秒多之内页面就停在了最顶上，而且这封信离顶端超过两屏半），没有在真机上验证过；最靠上的几封信不适用，会像往上滚出信纸一样合上。
- 没有在真的 iPhone 上看过：所有「手机」截图和测试都是 Playwright 的 WebKit（402 × 874）。
